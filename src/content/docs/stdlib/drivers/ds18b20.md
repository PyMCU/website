```python
from pymcu.drivers.ds18b20 import DS18B20
```

Driver for the DS18B20 1-Wire temperature sensor. `read()` returns a 12-bit raw value in
1/16 °C units.

`DS18B20` is a **PyMCU stdlib driver**, not part of MicroPython or CircuitPython — neither
ecosystem specifies a 1-Wire or DS18B20 class that PyMCU could mirror, so there is nothing to
switch between and this page shows a single API. You import it exactly as written above whichever
API you use for the rest of your program: a `machine.Pin` sketch and a `digitalio` sketch both say
`from pymcu.drivers.ds18b20 import DS18B20`, and it compiles to the same code in both.

:::note[AVR only]
The 1-Wire timing back end is implemented for AVR (`pymcu.drivers._ds18b20.avr`). On any other
architecture `read()` returns the error sentinel `-32768`. To add a target, drop a
`pymcu/drivers/_ds18b20/<arch>.py` next to the AVR one — the `DS18B20` class itself is
architecture-neutral.
:::

## `DS18B20(pin)`

| Parameter | Type | Description |
|---|---|---|
| `pin` | `str` | Port/pin name, `"PD2"`–`"PD7"`. Bound at compile time — no SRAM is allocated. |

On the ATmega328P the pin must be `"PD2"` through `"PD7"` — D2 to D7 on an Arduino Uno. `PD0`
and `PD1` are excluded because they are the hardware UART's RX and TX; they have no dispatch
case, so `DS18B20("PD0")` compiles and then returns the error sentinel `-32768` forever.

### DS18B20 methods

| Method | Return type | Description |
|---|---|---|
| `read()` | `int16` | Full 1-Wire transaction; raw 12-bit value in 1/16 °C, or `-32768` on error |
| `read_celsius_x16()` | `int16` | Alias for `read()` — same result |

### Return value encoding

| Raw value | Meaning |
|---|---|
| `>= 0` | Temperature in 1/16 °C units |
| `-32768` | Sensor error — no device present on the bus, or a presence-pulse/read timeout |

To split the raw value into whole and fractional degrees:

```python
raw: int16 = sensor.read()
if raw != -32768:
    temp_c: int = raw >> 4           # integer part, degrees Celsius
    frac:   int = (raw & 0xF) * 625  # fractional part, in 1e-4 degC
```

## Examples

### Basic temperature read

```python
from pymcu.drivers.ds18b20 import DS18B20
from pymcu.hal.uart import UART
from pymcu.time import delay_ms
from pymcu.types import int16

def main():
    sensor = DS18B20("PD4")
    uart = UART(9600)
    uart.println("DS18B20 ready")

    while True:
        raw: int16 = sensor.read()
        if raw == -32768:
            uart.println("sensor error")
        else:
            temp_c: int = raw >> 4
            uart.write_str("temp=")
            uart.print_byte(temp_c)
        delay_ms(1000)
```

### Reporting with an f-string

f-strings are supported both streamed and as values, so the whole/fractional split reads
naturally:

```python
from pymcu.drivers.ds18b20 import DS18B20
from pymcu.hal.uart import UART
from pymcu.time import delay_ms
from pymcu.types import int16

def main():
    sensor = DS18B20("PD4")
    uart = UART(9600)

    while True:
        raw: int16 = sensor.read()
        if raw != -32768:
            whole: int = raw >> 4
            cents: int = ((raw & 0xF) * 100) >> 4
            uart.println(f"T={whole}.{cents:02d}C")
        delay_ms(1000)
```

### Wiring

```text
Arduino Uno          DS18B20
-----------          -------
PD4 (D4)    <-->     DATA
5V          <-->     VCC
GND         <-->     GND
```

Add a **4.7 kΩ pull-up** between DATA and VCC — it is required by the open-drain 1-Wire bus.

## Notes

- One sensor per pin. The driver issues a SKIP ROM, so multi-drop addressing is not supported.
- A 12-bit conversion takes 750 ms and `read()` blocks for the whole conversion.
- The bus timing is built on `delay_us()`. Disable interrupts around the read if a
  timing-sensitive ISR can preempt it.
- `PD2`–`PD7` only on the ATmega328P (pin-mapping constraint of the AVR back end); `PD0` / `PD1`
  are reserved for the UART.
